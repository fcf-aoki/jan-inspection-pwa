【設置】
1. ZIPを展開し、5ファイルを同じフォルダーに置きます。
2. GitHub PagesなどHTTPS配信可能な場所に5ファイルをアップロードします。
   GitHub Pagesの場合、リポジトリの Settings > Pages で公開ブランチを指定します。
3. 公開URLをChrome（Android）またはEdge（Windows）で開きます。
4. Android: ブラウザのメニュー > アプリをインストール（またはホーム画面に追加）。
   Windows: Edgeのメニュー > アプリ > このサイトをアプリとしてインストール。
5. オンラインで初回起動後、オフライン動作・USB HID・保存/復元を検証します。

【注意】
・file://でindex.htmlを開くだけではPWAのインストールやオフラインキャッシュは有効になりません。
・公開GitHub Pagesは原則公開サイトです。業務上の機密情報や実データを含むファイルは公開しないでください。
・端末・ブラウザ・インストール方法が変わると保存領域が異なる場合があります。JSONバックアップを取得してください。
・オフラインは初回オンラインアクセス後のキャッシュ成功が前提です。
・既存アプリのJavaScriptロジックには変更を加えていません。読取と制御コードは実機で再検証してください。
・更新時にキャッシュの旧版が残ることがあります。運用開始前にバージョン管理・更新手順を決めてください。
